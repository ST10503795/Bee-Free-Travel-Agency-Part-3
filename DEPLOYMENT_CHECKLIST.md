# Part 3 deployment checklist

1. Open `index.html` using VS Code Live Server and test all six navigation links.
2. Search for Paris and filter beach escapes. Open and close a destination photo.
3. Check the map with an internet connection.
4. Test blank fields, invalid email, past departure date and return before departure.
5. IMPORTANT: the contact and enquiry forms currently open a mail client; they do not send automatically. Configure and test a real email service/AJAX endpoint before claiming full rubric email compliance.
6. Obtain actual Part 2 lecturer feedback and record the changes that respond to it.
7. Make several real, descriptive Git commits as work progresses; do not fabricate a commit history.
8. Deploy to GitHub Pages or Netlify. Confirm the exact public URL and then generate a correct sitemap.xml using that URL.
9. Verify every page and image on the deployed website, including mobile layouts.
10. Add deployment URL and verified test evidence to README.
