1. Project Overview

Bee Free Travel Agency is a small business website developed to present travel services, destinations and accommodation options to potential customers.

The purpose of this project is to create a website that is visually appealing, easy to navigate and suitable for a travel agency that focuses on providing customers with travel experiences and holiday opportunities.

The website was developed using HTML and CSS, with a focus on page structure, styling, responsive layouts and user-friendly navigation.

The design takes inspiration from existing travel industry websites while maintaining its own identity through the Bee Free branding, colour choices, content and page structure.

The website is intended to provide visitors with a simple way to explore destinations, view hotel information, learn about the business and submit a travel quotation request.

2. Project Objectives

The main objectives of the project are:

To develop a structured and functional small business website using HTML and CSS.
To create a consistent design across all website pages.
To provide clear navigation between the different sections of the website.
To present travel destinations and accommodation information in an organised manner.
To create a quotation request form for potential customers.
To apply CSS styling techniques such as Flexbox, Grid, spacing, typography and colour.
To make the website responsive across desktop, tablet and mobile screen sizes.
To apply user-centred design principles when organising website content.
To demonstrate the knowledge and skills gained during the Web Development module.

6. Design Approach

The design of Bee Free Travel Agency focuses on creating a clean, professional and welcoming appearance.

The website uses a combination of navy blue, white, light blue-grey and green accents to create a consistent visual identity.

The design decisions were influenced by research into existing travel websites and the principles of user-centred design.

6.1 Colour Scheme

The main colours used in the design include:

Navy blue: Used for headings, navigation elements and important buttons.
White: Used to maintain a clean and readable layout.
Light blue-grey: Used for selected backgrounds and content sections.
Green: Used as an accent colour to support the Bee Free identity.
Neutral grey: Used for supporting text, borders and secondary elements.
6.2 Typography

Typography is used to establish a clear hierarchy between headings, paragraphs, labels and buttons.

The design uses Montserrat and Playfair Display font families, with suitable fallback fonts where required.

6.3 Layout

The website uses CSS layout techniques to organise content and improve readability.

These include:

Flexbox for arranging navigation and horizontal content.
CSS Grid for presenting destination and travel cards.
Consistent spacing and margins.
Rounded corners and borders on selected content sections.
Clear separation between headings, paragraphs and calls to action.
7. HTML and CSS Implementation

The HTML and CSS development stage focuses on improving the original website structure and applying a consistent design across the different pages.

7.1 HTML Structure

Semantic HTML elements are used where appropriate to organise website content.

Examples include:

header
nav
main
section
article
footer
form

These elements help separate the different parts of each webpage and make the structure easier to understand and maintain.

7.2 External CSS

The website uses an external stylesheet located in:

CSS_STYLE/STYLES.css

The stylesheet is linked to the HTML pages using relative file paths.

This allows the website to maintain a consistent appearance without repeating the same styling rules in every HTML document.

7.3 Responsive Design

Responsive CSS techniques are used to support different screen sizes.

The stylesheet includes media queries for tablet and mobile layouts.

The responsive design focuses on:

Adjusting content widths.
Rearranging grid layouts.
Improving navigation on smaller screens.
Preventing content from overflowing.
Making buttons and forms easier to use on mobile devices.
7.4 Interactive Styling

CSS pseudo-classes are used to provide visual feedback when users interact with website elements.

These include:

:hover
:focus
:active

They are applied where appropriate to navigation links, buttons and form controls.

8. User Experience and Accessibility Considerations

The website follows a user-centred approach by focusing on how visitors interact with the content.

The following considerations guide the design:

Clear navigation between pages.
Readable text and suitable contrast.
Consistent headings and page layouts.
Descriptive image alternative text where applicable.
Clearly labelled form fields.
Visible interaction states for links and buttons.
Responsive layouts for different devices.
Organised content that allows visitors to find information without unnecessary difficulty.
